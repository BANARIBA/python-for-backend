# Blogs api

# Dependencias
- [FastAPI](https://fastapi.tiangolo.com/#installation)
- [Pydantic](https://pydantic.dev/docs/validation/latest/get-started/install/)
- [SQLAchemy](https://www.sqlalchemy.org//)
- [Pyodbc](https://pypi.org/project/pyodbc/)
- [Driver sql server windows 17 o superior](https://learn.microsoft.com/es-es/sql/connect/odbc/download-odbc-driver-for-sql-server?view=sql-server-ver17)
- [JWT y OAuth](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/) ```pip install pyjwt, pip install "pwdlib[argon2]"```

1. Correr proyecto
- Crear venv ```py -m venv venv```
- Entrar Directorio ```venv/Scripts/activate```
- Instalar paqueteria
- Comando ```fastapi dev main.py```
